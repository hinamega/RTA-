# Discordサーバー設計・運用ガイド

オンラインRTAイベントを事故なく円滑に運営するための、Discordサーバー構築テンプレートと権限設計ガイドです。

---

## クイックスタート：自動構築スクリプトを使う場合（推奨）

手動でチャンネルやロールを1つずつ作る必要はありません。同梱の自動構築ツールを実行すれば、わずか数秒でサーバー全体が完成します。

### 自動構築の手順
1. Discordで「新規サーバー」を空の状態で作成します。
2. [Discord Developer Portal](https://discord.com/developers/applications) でBotを作成し、対象サーバーに「管理者（Administrator）」権限で招待します。
3. `tools/Discordサーバー自動構築.bat` をダブルクリックして実行します。
4. 画面の案内に従って「Bot Token」と「サーバーID（Guild ID）」を入力すると、全ロール・チャンネル・権限が一括で自動構築されます！
5. 構築完了後、サーバー設定から「サーバーテンプレート」を発行すれば、他の人へURLで配布できます。

---

## サーバーテンプレート機能による配布・複製について

Discordには**「サーバーテンプレート」**という公式機能が備わっています。
一度理想のサーバー（チャンネル、ロール、権限設定）を構築してテンプレートURLを発行すれば、他の主催者はそのURLを開くだけで**1クリックでまったく同じ構成のサーバーを新規作成**できます。

※ テンプレートで複製されるもの：チャンネル一覧、カテゴリ構成、ロール一覧、各権限設定、チャンネルトピック
※ 複製されないもの：過去のメッセージ、参加メンバー、Webhook設定など（完全に新しいサーバーとして立ち上がります）

## 1. ロール（役職）一覧と権限設計

誤爆や配信事故（知らない人が本番VCに入って声が乗る等）を防ぐため、権限を最小限かつ明確に分離します。

| ロール名 | 付与対象 | 主な権限・役割 | 表示順（上から） |
|---|---|---|---|
| **運営 / 主催** | 主催者、配信担当スタッフ | サーバーの全管理権限（管理者） | 1番上 |
| **走者** | 採用が確定したRTA走者 | 走者限定連絡の閲覧・投稿、控室・テスト用VCへのアクセス | 2番目 |
| **解説** | 採用が確定した解説者 | 走者限定連絡の閲覧・投稿、控室・テスト用VCへのアクセス | 3番目 |
| **応募者** | フォーム応募完了後に参加した人 | 一般告知・質問チャンネルの閲覧および発言 | 4番目 |
| **@everyone** | 参加者全員（初期状態） | 重要告知の閲覧のみ（荒らし防止のため書き込み・VC入室は禁止） | 最下部 |

## 2. カテゴリ・チャンネル構成一覧

```text
[インフォメーション]（全員閲覧用）
├ 📜 #はじめに（イベント概要・基本ルール・必読案内）
├ 📢 #公式アナウンス（募集開始、当落発表、タイムテーブル公開など）
└ ❓ #質問・問い合わせ（応募前・参加前の疑問解消）

[走者・解説連絡]（「走者」「解説」「運営」ロールのみ閲覧可）
├ 📌 #走者向け重要連絡（提出物締め切り、スケジュール案内）
├ 🎨 #素材提出（走者アイコン、レイアウト希望などの受け取り）
├ 🛠️ #リハーサル日程調整（事前接続テストの日時調整）
└ 💬 #走者控室・雑談（走者同士の交流・連絡用テキスト）

[本番・控室通話]（ボイスチャンネル）
├ 🔴 本番配信ステージ（本番中の走者＋解説＋運営のみ入室可）
├ ⏳ 次走者・待機控室（次の出番の走者・解説が準備待機する部屋）
├ 🔧 接続テスト・リハ用VC（マイク音量・配信画面の確認部屋）
└ 🔒 運営専用VC（裏方連絡用）
```

## 3. 事故を防ぐための権限設定ポイント

### ① 本番配信VCの「入室ロック」
- **目的**: 配信中に無関係なユーザーが誤って入室し、声や雑音が配信に乗る事故を100%防ぐ。
- **設定**:
  - `@everyone`: 「接続」権限を ❌（無効）に設定
  - `走者` `解説` `運営`: 「接続」権限を ⭕（有効）に設定
  - ※ 接続人数制限（User Limit）を「3〜4名」に絞っておくのも有効です。

### ② 応募者ロールによるスパム・荒らし対策
- **目的**: サーバー招待リンクから入ってきただけの未認証アカウントによるスパム爆撃を防ぐ。
- **設定**:
  - `@everyone` は基本的に「メッセージ送信」を ❌（無効）にする。
  - Googleフォーム応募完了画面に案内を載せるか、ルール同意ボタン（Onboarding機能）で「応募者」ロールを付与し、書き込み権限を開放する。

### ③ 走者限定カテゴリの完全非公開化
- **目的**: 当落発表前の情報漏洩や、走者間のプライベートな連絡を守る。
- **設定**:
  - 「走者・解説連絡」カテゴリのプライベート設定をONにし、`走者` `解説` `運営` ロールのみを追加する。

## 4. サーバーテンプレートの発行・利用手順

### テンプレートの作成手順（配布側）
1. Discordのサーバー名の横にある「▼」をクリックし、**「サーバー設定」** を開く。
2. 左メニューから **「サーバーテンプレート」** を選択。
3. テンプレート名（例: `RTAイベント運営テンプレート（単走版）`）と説明を入力。
4. **「テンプレートを生成」** をクリックすると、共有用URL（`https://discord.new/...`）が発行されます。

### テンプレートからの作成手順（利用者側）
1. 発行されたテンプレートURLをブラウザで開く。
2. 「サーバー名」を入力し、**「作成」** を押すだけで、上記チャンネル・ロール構成のサーバーが即座に立ち上がります。
