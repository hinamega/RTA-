# VODチャプター自動生成 & 事故検知アラート ガイド

配信後のアーカイブ整理（VODチャプター）と、ワンオペ運営の事故を Discord に通知する仕組みのガイドです。

---

## 1. VODチャプター自動生成

### 仕組み
各走者の **実走開始時刻** をもとに、Twitch / YouTube 用のチャプター文字列を自動生成します。

- 実走開始時刻（`actual_start`）は、[LiveSplit 連携](livesplit_integration_guide.md) または手動タイマーの START 時に自動記録されます。
- 記録がない走者は、スケジュールの **予定開始時刻（`scheduled_at`）** をフォールバックとして使用します。

### 使い方
1. ダッシュボードの **「🎬 VODチャプター自動生成」** カードを開きます。
2. 必要に応じて **配信開始時刻** を入力します。
   - 未入力の場合、最初の走者が `0:00:00` になります。
   - 配信の冒頭に挨拶や待機時間がある場合は、実際の配信開始時刻を入れるとズレません。
3. **「📝 チャプター生成」** をクリックします。
4. **「📋 クリップボードにコピー」** を押して、Twitch の VOD 編集画面や YouTube の概要欄に貼り付けます。

### 出力例
```text
0:00:00 オープニング
0:05:00 Super Mario 64 (16 Star) - ひなめが
0:10:30 Celeste (Any%) - てち
```

> [!NOTE]
> Twitch のチャプターは **先頭が `0:00`** である必要があります。冒頭にオープニングがある場合は自動で挿入されます。

### 実走記録のリセット
テスト走行などで記録した時刻を消したい場合は、**「実走記録をクリア」** を押してください。次回の本番前にまっさらにできます。

## 2. 事故検知アラート（Discord通知）

ワンオペ運営で「気づけない事故」を Discord に通知します。

### 通知される内容

| 種類 | タイミング |
| --- | --- |
| 🚨 LiveSplit 切断 | 接続中だった LiveSplit が切断されたとき |
| ⏰ 予定タイム超過 | 走行中のタイムが予定（EST）を一定％以上オーバーしたとき |
| ⏳ 出走リマインド | 次の走者の予定開始時刻が近づいたとき |
| 🆘 SOS | ダッシュボードの SOS ボタンを押したとき（手動） |
| 🔔 テスト | テスト送信ボタンを押したとき（手動） |

### Discord Webhook の作成手順
1. 通知したい Discord サーバーで、任意のテキストチャンネルを右クリックします。
2. **「チャンネルの編集」** → **「連携サービス」** → **「ウェブフック」** を開きます。
3. **「新しいウェブフック」** を作成し、名前を設定します。
4. **「ウェブフックURLをコピー」** をクリックします。
5. ダッシュボードの **「🚨 事故検知アラート」** カードの **Discord Webhook URL** に貼り付けます。

### 設定項目

| 項目 | 説明 |
| --- | --- |
| Discord 通知を有効化 | ONで通知を送信します |
| メンション | 通知時に付けるメンション。例: `@here` や `<@&ロールID>` |
| LiveSplit 切断を通知 | 接続が切れたときに通知 |
| 予定タイム超過を通知 | 走行中のタイム超過を通知 |
| 超過アラート閾値 (%) | 予定タイムから何％超えたら通知するか（例: 20） |
| 出走リマインドを通知 | 次の走者の予定開始が近づいたら通知 |
| リマインド（何分前） | 何分前に通知するか（例: 5） |

- **🔔 テスト送信** で通知が届くか事前確認できます。
- **🆘 SOS送信** は、想定外のトラブル時にメンバーへ一斉に助けを求められます。

> [!WARNING]
> Webhook URL は「投稿用の鍵」です。第三者に知られると誰でも投稿できてしまうため、取り扱いには注意してください。URLはローカルの設定DBにのみ保存され、リポジトリにはコミットされません。

---

## 3. 運用のコツ

- 本番前に **テスト送信** で通知先を確認しておく。
- リマインドは、予定時刻どおりに進行しているときだけ鳴ります。押し／巻きが大きいイベントでは、予定時刻をこまめに更新すると精度が上がります。
- LiveSplit 切断通知は、走者が一時的に配信を止めただけでも鳴ることがあります。頻繁すぎる場合は通知をオフにするか、`@here` メンションを外しましょう。
