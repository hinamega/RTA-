## 概要と目指したいこと

オンラインRTAイベントの開催は、走者募集からスケジュール選定、リハーサル、本番の画面・音声管理、終了後のアフターフォローまで多岐にわたり、属人化しやすい傾向があります。

このプロジェクトでは、**「イベント運営の知識や経験が少なくても、募集から終了後のアンケートまで迷わず機械的に回せる状態」** を目指して、配信管理システム（NodeCG）のスターターキット、各種マニュアル、運用テンプレート一式を整備していきたいと考えています。

まずは確実にやり切るスコープとして、**「単走（走者1名＋解説0〜数名）」** の運用をターゲットに設計を進めています。

## 基本方針・大切にしたいこと

### 1. システムと自動化は「裏方」に徹する
- コマンド操作に不慣れな人でも、ダブルクリックだけで起動できるようにしたい
- 画面切り替えや走者情報の更新、配信サイト連携などを、当日なるべく少ない手間で完結できる仕組みを目指す
- 本番中のオペレーション負荷を減らし、ワンオペでも進行トラブルを未然に防げるようにしたい

### 2. 規格化されたデザインシステムを採用し、誰でも使いやすく・見やすくする
- デジタル庁デザインシステム（DADS）をはじめとする、検証済みの確立されたデザインガイドライン・ユニバーサルデザインを採用する
- 8pxグリッド、高いコントラスト比、整理された文字階層（ジャンプ率）をベースにすることで、誰が作っても情報が破綻せず、あらゆる視聴者にとって読みやすい画面構成を保つ
- テーマカラーやイベントロゴ、配色の差し替えだけで、専門的なデザイン知識がなくても誰でも一瞬で美しく洗練された配信画面を構築できる状態を目指す

## カバーするイベント全体のライフサイクル

本キットでは、単なる配信ツールにとどまらず、イベントの立ち上げから終了後までの全行程を手順化・テンプレート化していく予定です。

```text
[1. 応募フォーム] 
       ↓ (スプレッドシート自動集計)
[2. 選定＆タイムテーブル策定] 
       ↓ (スケジュール JSON / CSV 出力)
[3. 事前準備・リハーサル] 
       ↓
[4. 本番・NodeCGワンオペ配信管理] ──> ボタン1つで画面・走者情報・Twitchタイトルが完全同期
       ↓
[5. 〆・振り返り・アンケート]
```

### 1. 募集フェーズ
- 走者・解説・運営スタッフの応募用 Google フォーム設計案
- 募集告知文・参加規約・ガイドラインのテンプレート

### 2. 選定・スケジュール策定フェーズ
- 応募データの整理とタイムテーブル作成用スプレッドシート
- 当落・出演確定の連絡メッセージ用テンプレート

### 3. 事前準備・リハーサルフェーズ
- 走者向け接続テスト・配信設定チェックリスト
- Discord サーバーのチャンネル構成・権限設定テンプレート

### 4. 本番・配信管理フェーズ（NodeCGスターターキット）
- **「単走トラック（1画面）」** 特化の直感的な配信ダッシュボード
- OBS連携オーバーレイ（16:9 / 4:3 対応、走者・解説名、タイマー表示）
- スケジュール JSON のインポート＆1クリック切り替え機能
- Twitch API 連携による「配信タイトル / カテゴリ」の自動更新

### 5. 振り返り・アフターフォローフェーズ
- 参加者・視聴者向けアンケートフォーム
- 配信アーカイブ（VOD）のタイムスタンプ付き目次生成
- 走者・スタッフへの御礼連絡テンプレート

## 採用技術スタック

- **配信管理エンジン**: [NodeCG](https://nodecg.dev/) (v2.x)
- **フロントエンド / UI**: HTML5 / CSS3 (Digital Agency Design System, Vanilla JS)
- **配信ソフト連携**: OBS Studio (Browser Source)
- **自動化・データ連携**: Google Apps Script (GAS), Twitch Helix API
- **動作環境**: Windows 10 / 11 (Node.js v18+)

## スケジュールデータ形式（JSON仕様案）

本キットで扱うスケジュールデータの標準フォーマットです。Google スプレッドシートからこの形式で出力してインポートします。

```json
[
  {
    "id": "run-01",
    "order": 1,
    "scheduled_time": "2026-06-20T10:00:00+09:00",
    "game": {
      "title": "ゲームタイトル",
      "category": "Any%",
      "platform": "PC / Switch / etc",
      "aspect_ratio": "16:9",
      "est": "00:45:00"
    },
    "runner": {
      "name": "走者名",
      "furigana": "ソウシャメイ",
      "twitch": "twitch_id",
      "twitter": "twitter_id",
      "discord_id": "user#1234"
    },
    "commentators": [
      {
        "name": "解説者名",
        "twitter": "twitter_id"
      }
    ]
  }
]
```
