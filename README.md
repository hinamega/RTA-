# オンラインRTAイベント「誰でもワンオペ機械化」スターターキット（構想ドラフト）

> ※ このドキュメントは、AIと壁打ちしながらざっくりまとめた構想・計画段階のドラフトです。実際の運用やフィードバックをもとに随時更新・見直しを行っていく予定です。

---

## 概要と目指したいこと

オンラインRTAイベントの開催は、画面切り替えや走者管理、各種トラブル対応など覚えることが多く、属人化しやすい傾向があります。
このプロジェクトでは、**「運営や技術の知識がそれほどなくても、仕組み化と分かりやすいマニュアルで無理なく回せる状態」** を目指して、配信管理システム（NodeCG）のスターターキットやテンプレート類を整備していきたいと考えています。

---

## 基本方針・大切にしたいこと

### 1. システムと自動化は「裏方」に徹する
- コマンド操作に不慣れな人でも、ダブルクリックだけで起動できるようにしたい
- 画面切り替えや走者情報の更新、配信サイト連携などを、当日なるべく少ない手間で完結できる仕組みを目指す
- 本番中のオペレーション負荷を減らし、進行トラブルを未然に防げるようにしたい

### 2. デザインや表現は人間の手で自由に彩れるようにする
- AI生成のイラストや固定されたデザインを押し付けるのではなく、人間が手を加えやすい「枠組み・余白」を重視したテンプレート構成にする
- オーバーレイの背景画像、枠線、ロゴ、配色、フォントなどは、各イベントの主催者やデザイナーが自由に差し替え・カスタマイズできる設計にしたい
- それぞれのイベントが持つ個性や世界観を、人の手でしっかり表現できる状態を保ちたい

---

## 用意していきたいもの（予定）

### 配信システム (NodeCG)
- 初回セットアップや起動を簡略化するバッチファイル
- 走者名、ゲームタイトル、タイマー等の管理ダッシュボード
- OBS等に配置しやすいブラウザソース用オーバーレイのベース

### 運用マニュアル
- 初心者向けのNode.js・OBS導入ガイド
- 当日の進行・操作手順書
- よくある音声・配信トラブルのチェックリスト

### テンプレート・運用資料
- 走者・解説応募用のフォーム設計案
- 進行台本・Discord連絡用のスプレッドシート
- 事故を防ぐためのDiscordサーバー構成案
