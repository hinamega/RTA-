## 概要と目指したいこと

オンラインRTAイベントの開催は、走者募集からスケジュール選定、リハーサル、本番の画面・音声管理、終了後のアフターフォローまで多岐にわたり、属人化しやすい傾向があります。

このプロジェクトでは、**「イベント運営の知識や経験が少なくても、募集から終了後のアンケートまで迷わず機械的に回せる状態」** を目指して、配信管理システム（NodeCG）のスターターキット、各種マニュアル、運用テンプレート一式を整備していきたいと考えています。

まずは確実にやり切るスコープとして、**「単走（走者1名＋解説0〜数名）」** の運用をターゲットに設計を進めています。

## 基本方針・大切にしたいこと

### 1. システムと自動化は「裏方」に徹する
- コマンド操作に不慣れな人でも、ダブルクリックだけで起動できるようにしたい
- 画面切り替えや走者情報の更新、配信サイト連携などを、当日なるべく少ない手間で完結できる仕組みを目指す
- 本番中のオペレーション負荷を減らし、ワンオペでも進行トラブルを未然に防げるようにしたい

### 2. 規格化されたデザインシステムを採用し、誰でも使いやすく・見やすくする
- デジタル庁デザインシステム（DADS）をはじめとする、検証済みの確立されたデザインガイドライン・ユニバーサルデザインを採用する
- 8pxグリッド、高いコントラスト比、整理された文字階層（ジャンプ率）をベースにすることで、誰が作っても情報が破綻せず、あらゆる視聴者にとって読みやすい画面構成を保つ
- テーマカラーやイベントロゴ、配色の差し替えだけで、専門的なデザイン知識がなくても誰でも一瞬で美しく洗練された配信画面を構築できる状態を目指す

## カバーするイベント全体のライフサイクル

本キットでは、単なる配信ツールにとどまらず、イベントの立ち上げから終了後までの全行程を手順化・テンプレート化していく予定です。

```text
[1. 応募フォーム] 
       ↓ (スプレッドシート自動集計)
[2. 選定＆タイムテーブル策定] 
       ↓ (スケジュール JSON / CSV 出力)
[3. 事前準備・リハーサル] 
       ↓
[4. 本番・NodeCGワンオペ配信管理] ──> ボタン1つで画面・走者情報・Twitchタイトルが完全同期
       ↓
[5. 〆・振り返り・アンケート]
```

### 1. 募集フェーズ
- 走者・解説・運営スタッフの応募用 Google フォーム設計案
- 募集告知文・参加規約・ガイドラインのテンプレート

### 2. 選定・スケジュール策定フェーズ
- 応募データの整理とタイムテーブル作成用スプレッドシート
- 当落・出演確定の連絡メッセージ用テンプレート

### 3. 事前準備・リハーサルフェーズ
- 事故を防ぐ Discord サーバー構築テンプレート（[詳細ガイドはこちら](docs/discord_setup_guide.md)）
- 走者向け事前接続テスト・リハーサル手順書
- 配信素材（ロゴ・背景・走者アイコン等）の受け取り・配置ガイド

### 4. 本番・配信管理フェーズ
- NodeCG＆OBS のダブルクリック起動パッケージ
- ワンクリックで完結する画面切替・走者情報更新・Twitchタイトル変更
- トラブル対応チェックリスト（回線落ち、音声バランス、映像乱れ等）

### 5. 〆・振り返りフェーズ
- イベント終了後の御礼告知文テンプレート
- 走者・視聴者向け振り返りアンケート（Google フォーム設計案）
- アーカイブ（VOD）整理・切り抜き公開フロー

## データ連携の基本設計（ドラフト）

手戻りと属人化をなくすため、応募フォームで集めたデータをそのままNodeCGの制御用JSONへ変換できるデータ構造を定義しています。

### 応募フォームで収集する主な項目（要件案）
- **走者情報**: 走者名、フリガナ、Discord ID（必須）、Twitch ID（必須）、X(Twitter) ID
- **ゲーム情報**: タイトル、カテゴリ、機種/プラットフォーム、アスペクト比（16:9 / 4:3）、EST（予定タイム）、自己ベスト、参考動画URL
- **環境・解説**: 解説の有無/同行者情報、希望・参加可能時間帯、通信環境（有線/無線など）

### スケジュールJSON構造（単走向けドラフト）
```json
[
  {
    "id": "run-001",
    "order": 1,
    "scheduled_at": "2026-09-01T13:00:00+09:00",
    "game": {
      "title": "Super Mario 64",
      "category": "16 Star",
      "platform": "N64",
      "aspect_ratio": "4:3",
      "est": "00:20:00",
      "setup_minutes": 10
    },
    "runner": {
      "name": "走者名",
      "furigana": "ソウシャメイ",
      "twitch": "twitch_id",
      "twitter": "twitter_id",
      "discord_id": "user#1234"
    },
    "commentators": [
      {
        "name": "解説者名",
        "twitter": "twitter_id"
      }
    ]
  }
]
```
