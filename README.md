# 🎮 オンラインRTAイベント「誰でもワンオペ機械化」スターターキット

> **「運営の知識がなくても、徹底した自動化とマニュアルで機械的に回せる」**
> 
> オンラインRTAイベントの開催ハードルを極限まで下げるための、配信管理システム（NodeCG）＋運用マニュアル＋各種テンプレート一式です。

---

## 💡 プロジェクトの思想とこだわり

### 1. ⚙️ システムと自動化は「裏方」に徹する
- コマンド操作やプログラミングの知識は一切不要。
- ダブルクリックだけで起動し、画面切り替えや走者情報更新、Twitchタイトル更新を最小限のクリック数で完結させます。
- 当日のオペレーションを極限まで脳死化し、トラブルの起きない設計を目指します。

### 2. 🎨 デザインとクリエイティブは「人の手」で自由に彩る
- **AI生成画像や固定デザインを押し付けない、柔軟なテンプレート構造**を採用しています。
- オーバーレイの背景画像、枠線、ロゴ、フォント、配色などは、主催者やクリエイターが自由に差し替え・デザインできる「余白」を大きく残しています。
- 各イベントの個性や世界観を、人間の手で思い通りに表現できます。

## 📦 提供するもの（予定）

| カテゴリ | 内容 |
|---|---|
| **💻 配信システム (NodeCG)** | ・ダブルクリックで起動するワンクリック環境<br>・走者名・ゲーム名・タイマー・Twitch連携ダッシュボード<br>・OBSにそのまま貼れるブラウザソース用オーバーレイ |
| **📖 運用マニュアル** | ・Node.js / OBS の初心者向け図解セットアップガイド<br>・当日のオペレーション進行手順<br>・配信・音声トラブル対応チェックリスト |
| **📋 テンプレート一式** | ・走者・解説募集用 Google フォーム定義<br>・コピペで使える進行台本＆Discord案内用スプレッドシート<br>・事故を防ぐ Discord サーバー構築テンプレート |
